# Python Projects

A collection of Python projects built while relearning programming fundamentals.

## Projects

### Quiz Game
A command-line quiz game that asks 5 questions and tracks the user's score.

### Calculator
A simple calculator that performs addition, subtraction, multiplication, and division based on user input.

### To-Do List
A command-line to-do list app that lets users add, view, and delete tasks. Tasks are saved to a file so they persist after closing the program.
